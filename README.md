# All-Technologies-Study

My interview preparation notes, organised by technology and company.

| Folder | What it holds |
|---|---|
| `Companies-Interview/` | L1 interview questions and answers by company (Algoworks, Deloitte, Hitachi, Kyndryl, Persistent, TCS, TechM, UST, Wipro and more) |
| `Online Fetched Questions/` | Questions real candidates reported at named companies, as `Company/Technology/file.md` (Node.js, React, AI/LLM, Docker, JWT and more) |
| `NodeJs/` | Node.js and JavaScript questions (`questions/`) and programs (`programs/`) |
| `PHP/`, `Laravel/`, `MySQL/`, `jQuery/`, `React/`, `Web-General/` | Question lists by technology |
| `Youtube/` | Questions collected from interview videos on YouTube (`Node-Js-Developer-Interview-Questions/`, `AI/`) |
| `My Work/Notes/` | My own study notes (`nodejsNotes.txt`) |
| `My Work/Questions-&-Answers/` | One file per technology with every question asked in real interviews, ordered by how many interviewers asked it, with simple answers and a "What to study first" order at the end |
| `all-technologies-questions-priority.html` | Open in a browser: every technical question in the repo (all sources, all technologies), duplicates merged, topics ranked by priority |
