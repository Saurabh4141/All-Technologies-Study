# Rules for interview answers (My Work/Questions-&-Answers/*.md)

Follow these for every answer you write or edit:

1. Answer only the question asked. Don't add unrelated information.
2. Don't assume unspecified technologies. Only use the tools/libraries the question names.
3. Keep every question independent. Don't connect the current question to previous questions
   unless requested.
4. Don't introduce unrelated examples or application scenarios.
5. Use simple, human language that's easy to understand and remember.
6. Make answers interview-ready and technically accurate.
7. Explain one concept at a time. Don't overload the answer with multiple concepts.

Answers the user wrote by hand stay as written.
